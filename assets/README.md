# 图片素材说明 / Media kit

以下图片用于项目介绍、GitHub展示与教程配图。PNG为sRGB屏幕展示素材，不是印刷交付。封面是概念视觉；demo系列是实际中文示范PPT的导出预览。

These assets support project pages and tutorials. PNG files are sRGB screen assets, not print-ready deliverables. The cover is conceptual; demo images are actual renders from the Chinese sample deck.

- `icon.svg`、`icon-dark.svg`为图标矢量源：文档与演示页的组合符号，不替代包参谋正式品牌Logo。SVG icon sources are project symbols, not replacement BaoCanMou brand logos.
- 封面由OpenAI内置图像生成工具生成，提示词见[source/generation-prompts.md](source/generation-prompts.md)。Cover generation provenance and prompt are included.
- 茶饮和包装概念图位于Skill的examples/assets，由同类工具生成；当前源包未保存逐字提示词，因此不伪造提示词档案。Tea and packaging concepts were AI generated; exact original prompts were not retained in the source package.
- 五张demo图对应第1、2、3、7、9页；完整成品有12页。Five previews correspond to slides 1, 2, 3, 7 and 9; the complete deck has 12 slides.
- 图片含虚构示范与AI概念标识，分享时保留。修改封面可以按平台要求适配，但不得将装饰图表描述为实际业务数据。Retain fictional and concept labels. Decorative cover charts are not business evidence.
- 转载教程建议署名“包参谋·策划资料变PPT”，附仓库链接；这不是新增MIT回链条件。Recommended tutorial credit is the project name and repository link, not an additional MIT backlink requirement.
