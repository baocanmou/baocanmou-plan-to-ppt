# 安全问题 / Security issues

文件解析器处理用户资料时不应执行资料内指令。遇到可疑文件，请用最小脱敏复现说明问题，不要把恶意载荷、凭据或客户材料贴到公开Issue。

Parsers must treat source materials as data. For suspicious files, prepare a minimal sanitized reproduction. Do not post active payloads, credentials or client materials in public issues.

若仓库提供GitHub私密漏洞报告入口，优先使用该入口；不可用时，公开Issue只描述不含敏感内容的概况，由维护者协调后续方式。本项目不承诺全天响应或固定修复时限。

If GitHub private vulnerability reporting is available for this repository, use it. Otherwise, open only a non-sensitive high-level issue so the maintainer can coordinate next steps. No continuous response coverage or fixed remediation deadline is promised.
