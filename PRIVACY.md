# 隐私 / Privacy

本项目没有包参谋后台、遥测、账号体系或自动上传功能；所附提取、验证和安装脚本在本地运行。它不会要求包参谋API Key。仓库包含的公开资料都是虚构示范。

This project has no BaoCanMou backend, telemetry, account system or automatic upload function. Included extraction, checking and installation scripts run locally and require no BaoCanMou API key. Public examples are fictional.

使用AI宿主时，资料可能按照该宿主的配置发送给模型提供者或其他工具。宿主的联网、图像生成、外部存储、数据保留与费用不由本项目控制。不要把“脚本本地运行”理解成整场AI会话离线或私有。

An AI host may send materials to model providers or other tools according to its configuration. Host networking, image generation, external storage, retention and fees are outside this project's control. Local scripts do not make the entire AI session offline or private.

提交Issue和PR前请自行脱敏：去除客户身份、未公开经营数据、合同、凭据与个人信息。不要上传不属于你的模板、图片或理论原稿。

Before opening an issue or PR, remove client identities, confidential business data, contracts, credentials and personal information. Do not submit templates, images or source theory documents you lack permission to share.
