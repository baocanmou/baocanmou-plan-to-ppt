# v1.1.0 验证说明

验证日期：2026-09-10。结论：本机已完成从资料到真实 PPTX 的制作与导出，提供可复查的完整示范；没有证据认定“全网第一”。

## 已经实测

| 项目 | 结果与范围 |
|---|---|
| 完整样例 | 4份虚构资料、27段来源，整理为12页提案、20条事实、建议或待确认项 |
| 资料差异 | 保留9万元旧讨论；按明确的负责人修订采用6万元、4周、南昌 |
| 自动回归 | 25项通过，覆盖资料顺序、编码、引用、数字、标签、预算求和、改稿影响、实际PPTX内容及谋术鸣承接关系 |
| 最终成品 | 12页；85个原生文字对象、3张原生表格、1张原生图表、1个嵌入式XLSX、2张图片 |
| 文件校验 | 最终PPTX通过包结构、声明的字体与尺寸、表格及图表数据检查，并通过Artifact Tool重新导入 |
| 数字负例 | 实际修改最终PPTX表格15000→15001、图表54→540，检查器均报告与计划不一致 |
| 可见说明 | 实际删除图表页的模拟样本说明，检查器报告缺失 |
| PDF与视觉 | 从v1.1最终PPTX导出12页PDF，检查全部页面渲染；中文字体全部嵌入，未观察到遮挡或文字溢出 |
| PDF再读取 | pypdf后端实际提取12页文字，无失败项；扫描PDF不在此测试范围 |

预算求和由 plancheck 的显式求和关系校验，pptxcheck 再比对实际表格数值。宿主自动推断的表格求和检查没有识别本样例的页脚合计，不能把该项“无发现”当作已经检查预算。

## 谋术鸣实测

新版示范采用工作假设模式：知为价值观中心，使命和价值观为建议，愿景未知；定位三问、设计认知任务、传播渠道与反馈记录对应关系。

新增5项检查实测通过：设计缺定位关联、传播缺设计关联、输入不足却声明完整应用、未知愿景缺可见说明均被拦截；非品牌计划可省略模型。检查器只检查声明和关联，不能自动判断定位质量或创始人信念。

另一名AI只阅读Skill与方法说明，实际完成6页通勤咖啡概念稿：未虚构价值观、竞品优势或用户数据，设计和传播承接同一定位假设。忠实周报案例未加品牌战略；该试用未附原始周表，只有3页承载结构，不能算完成了真实数据周报。两例均为逐页文字试用，未制作PPT。

试用发现“只要概念稿时停止”缺少明确分支，现已在快速路径补充。本轮旧版未知事实测试依赖某页没有说明；新版该页已有说明，已改为显式删除说明后验证拦截。

## v1.0 独立数字试用记录

让另一名AI执行者仅拿到本Skill与另一份虚构文具项目简报，独立整理6页计划。包含新旧预算冲突、80人模拟样本与未知销售条件。

| 实际输入变化 | 修复后的检查结果 |
|---|---|
| 正常计划 | 通过 |
| 16人误写为160人 | 拦截 |
| 短引用下交换两个类别 | 拦截 |
| 正常宽引用控制组 | 通过 |
| 宽引用下只交换类别 | 拦截 |

试用确实发现过错误数字漏检和宽引用下的类别错位漏检，现已加入数值及标签绑定。计算类事实仍提示人工核对单位和来源到算式的对应关系。检查不能自动理解所有商业语义，也不能防止人为一起篡改原资料和对应绑定。

同一份文具简报也交给未使用本Skill的独立AI完成大纲。普通助手同样正确处理了新旧预算与待确认信息，故本次不能证明Skill的策划文字一定更好。两次试用都是小样本，未做人工盲评，也未形成跨产品效果排名。

## 与已有产品的关系

“资料生成PPT”“可编辑导出”已有成熟实现，不能当作本项目的首创。例如：[Gamma官方说明](https://gamma.app/explore/content/guides/ai-tool-generate-presentation-editable-powerpoint)介绍可编辑PowerPoint导出；[Presenton官方项目](https://github.com/presenton/presenton)提供演示文稿生成工具；[Anthropic官方Skills项目](https://github.com/anthropics/skills/tree/main/skills/pptx)也提供PPTX技能。

本项目当前侧重将包参谋谋术鸣用于中文品牌提案，并处理资料整理、事实与建议区分、数字来源对应和改稿定位。这是产品取向，未证明其他产品不具备类似能力。本次只核对公开说明，没有付费购买并逐一实测这些产品。

## 仍待验证

- PowerPoint、WPS、Google Slides中的实际打开、修改及另存；原生OOXML结构不等于所有软件行为一致。
- Claude Code及其他宿主的完整生成链；本机安装入口存在不等于已经测试其生成。
- 真实客户材料、长提案、用户自带模板、扫描件和多语言复杂排版。
- 使用者完成时间、审美偏好、采纳率、传播数据和获客效果。

进一步比较应使用同一批脱敏资料、相同页数与交付要求，由策划和设计师匿名评审，并实际操作修改。公布可讲述性、数据错误、可编辑性和改稿时间的结果后，才能提出有依据的优势判断。
