# 把资料整理成能汇报的提案

先认出资料承担什么角色：客户要求、现场/访谈原话、经营数据、行业资料、创意方向、已定决策。不要把这六类内容混写成同样确定的结论。

## 选择这次需要的叙事

| 场合 | 听众需要 | 可采用的结构 |
|---|---|---|
| 品牌策略/营销方案 | 理解问题并选择方案 | 问题与证据 → 选择与理由 → 实施与验证 |
| 已签约成果提案 | 认可方案并安排落地 | 评估认同 → 方案展开 → 分工、排期、启动 |
| 售前建议 | 判断是否值得合作 | 需求理解 → 可提供的帮助 → 范围、投入与下一步 |
| 经营复盘 | 解释变化并作出调整 | 数据与口径 → 原因假设 → 调整及跟踪 |
| 培训/说明 | 能理解或完成一件事 | 背景 → 概念/步骤 → 示例 → 应用 |

此表提供选择，不要求每份 PPT 都套相同章节。沿用用户已确定的逻辑。

## 从原资料到每一页

例如原资料：“客户说想年轻化。现有包装消费者看不出产品类型。没有销售实验。”

可以写：“先把品类说清，再调整年轻化表达”，依据是材料中的识别问题；把设计调整列为建议。不能写“年轻化包装将提升销量30%”。

每页回答一件事，并选择匹配表达：

- 需要选择：给方案差异和取舍，避免只摆三张风格图。
- 需要相信：给原话、数据或实物，保留样本和时间范围。
- 需要理解：拆开关键概念或步骤，少堆形容词。
- 需要行动：写清下一步、负责人、约束与检查时点。

结论标题只用于证据支持的结论。简介、流程、数据口径页可直接命名主题。用中文自然表达，删除“赋能、全域增长闭环、战略势能跃迁”等无法落实到动作的句子。

预算是计划、目标是期望、样本结果是局部观察。保留这些差别，也保留单位、周期、比较对象和不确定性。

## 材料不足

可以交付有明确缺口的方案初稿，但在影响决策的页面可见地标记“待确认”或“试行建议”。来源缺失不能用通用行业说法填满；没有调研就不制造用户访谈。

## 方法来源

本技能由包参谋开发。品牌方案依据 [谋术鸣® 品牌定位设计模型](moushuming.md)：以价值观为中心，让定位推导设计、让设计与表达支持传播。知识与行动要对应；有视觉风格却没有定位依据，有渠道清单却没有内容与反馈，都属于需要补全的方案。

参谋五诊法、品牌源力提供评估和源力输入；谋术鸣组织方案内容；已签约成果提案可用三幕提案法讲述。分清这些方法的职责，不把它们合并成一个虚构的新模型。
